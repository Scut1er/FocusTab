# 📘 FocusTab — минималистичный Pomodoro-планировщик

FocusTab — это минималистичное веб-приложение, объединяющее Pomodoro-таймер, список задач и мотивационные цитаты. Оно создано для пользователей, которым нужен простой и быстрый инструмент для повышения фокуса без перегруженных интерфейсов, сложных меню и лишних функций.

Данный репозиторий представляет **вертикальный прототип (Release 1 / MVP)**, реализующий основной пользовательский сценарий:  
**запланировать задачу → запустить Pomodoro → завершить интервал → увидеть результат → продолжить работу.**

---

## ✨ Функциональность (Release 1)

### ⏱️ Pomodoro-таймер
- Стандартные интервалы: **25 минут работы** и **5 минут отдыха**
- Запуск и остановка таймера
- Визуальное уведомление о завершении интервала

### 📝 Минималистичный список задач
- Добавление задач
- Отметка задач как выполненных
- Удаление задач
- Локальное сохранение задач в браузере

### 💬 Мотивационные цитаты
- Отображение случайной цитаты из заранее подготовленного списка
- Обновление цитаты при обновлении страницы или завершении Pomodoro-сессии

### 🌙 Интерфейс
- Один экран, включающий таймер, задачи и цитату
- Минималистичный и интуитивный UX
- Мгновенный старт без регистрации

### 🔔 Уведомления
- Базовое визуальное уведомление о завершении Pomodoro

---

## 🛠️ Технологии
- HTML / CSS / JavaScript

- Web Audio API

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Scut1er/FocusTab.git
cd FocusTab
```

2. Откройте `index.html` в браузере или используйте локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (http-server)
npx http-server

# PHP
php -S localhost:8000
```

3. Откройте браузер и перейдите на `http://localhost:8000`
