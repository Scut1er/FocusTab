# FocusTab

Минималистичное веб-приложение для повышения продуктивности с таймером Pomodoro, списком задач и мотивационными цитатами.

## Возможности

- ⏱️ **Таймер Pomodoro** - стандартные интервалы (25 минут работа / 5 минут перерыв)
- ✅ **Список задач** - добавление, отметка выполнения, удаление (отображается до 5 задач с прокруткой)
- 💬 **Мотивационные цитаты** - случайные цитаты для поддержания фокуса
- 🔊 **Звуковые уведомления** - настраиваемые звуковые сигналы при завершении интервалов
- 🔔 **Браузерные уведомления** - системные уведомления поверх браузера/Windows
- 📊 **Статистика** - просмотр истории завершенных Pomodoro сессий
- 📱 **PWA** - работает оффлайн, можно установить как приложение
- 💾 **Локальное хранение** - все данные сохраняются в браузере

## Требования

- Современный браузер с поддержкой:
  - ES6+
  - localStorage
  - Service Workers (для PWA)
  - Web Audio API (для звуковых уведомлений)
  - Notifications API (для браузерных уведомлений)

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Scut1er/FocusTab.git
cd FocusTab
```

2. Откройте `index.html` в браузере или используйте локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (http-server)
npx http-server

# PHP
php -S localhost:8000
```

3. Откройте браузер и перейдите на `http://localhost:8000`

## Использование

### Таймер Pomodoro
- Нажмите **Старт** для начала рабочего интервала (25 минут)
- Нажмите **Пауза** для приостановки
- Нажмите **Сброс** для возврата к начальному значению (цитата обновится автоматически)
- После завершения рабочего интервала автоматически начинается перерыв (5 минут)
- После каждых 4 завершенных Pomodoro - долгий перерыв (15 минут)
- При завершении интервалов воспроизводится звуковое уведомление (если включено)

### Список задач
- Введите текст задачи и нажмите **Enter** или кнопку **+**
- Отметьте задачу как выполненную, кликнув на чекбокс
- Удалите задачу, наведя курсор и кликнув на **×**
- Отображается максимум 5 задач одновременно, остальные доступны через прокрутку
- Максимальная длина задачи: 500 символов

### Мотивационные цитаты
- Цитата отображается автоматически при загрузке страницы (всегда новая)
- Цитата обновляется при сбросе таймера
- Нажмите **Новая цитата** для получения другой цитаты вручную

### Настройки (⚙️)

#### Звуковые уведомления
- Используется файл `notification.mp3` из проекта
- Включите/выключите звук с помощью чекбокса "Включить звук"
- Нажмите **Тест звука** для проверки звукового сигнала
- Настройки сохраняются автоматически

#### Браузерные уведомления
- Отметьте чекбокс "Разрешить браузерные уведомления"
- Нажмите **Запросить разрешение** для получения доступа к системным уведомлениям
- После разрешения уведомления будут показываться поверх браузера/Windows при завершении интервалов
- Уведомления работают даже когда вкладка неактивна

### Статистика (📊)

Просмотр истории завершенных Pomodoro сессий:

1. Нажмите кнопку **📊** в правом верхнем углу
2. По умолчанию отображается статистика за последние 30 дней
3. Выберите диапазон дат:
   - **С** - начальная дата
   - **По** - конечная дата
   - Дата "С" должна быть меньше или равна дате "По"
4. Нажмите **Применить** для обновления данных

**Отображаемая информация:**
- **Сводка:**
  - Всего Pomodoro за период
  - Всего времени работы (часы и минуты)
  - Количество дней с активностью
- **Таблица по дням:**
  - Дата
  - Количество завершенных Pomodoro
  - Время работы (25 минут × количество Pomodoro)

## Технические детали

- **Хранение данных**: localStorage браузера
- **Префикс ключей**: `ft_`
- **Формат статистики**: `ft_stats_YYYY-MM-DD`
- **Максимальная длина задачи**: 500 символов
- **Звуковой файл**: `notification.mp3` (воспроизводится через Web Audio API)
- **Сохранение статистики**: автоматически при каждом завершенном Pomodoro

## Горячие клавиши

- **Enter** - добавить задачу (когда фокус в поле ввода)
- **Esc** - очистить поле ввода задачи
